# Mobile Sales Analysis Dashboard – Power BI

An interactive **Mobile Sales Analysis Dashboard** developed using **Microsoft Power BI** to analyze mobile sales performance, monthly trends, transaction types, payment methods, and geographical sales data.

## Project Overview

This project transforms mobile sales data into an interactive dashboard that provides clear insights into overall sales performance. The dashboard allows users to analyze sales based on **month, transaction type, payment method, and location**.

## Key Analysis

* Analyzed **monthly sales trends** to identify changes in sales performance.
* Analyzed transactions using **UPI, Debit Card, Credit Card, and Cash** payment methods.
* Performed **transaction-wise and payment-wise analysis**.
* Analyzed sales performance based on **geographical locations**.
* Used interactive filters to explore sales data dynamically.
* Created **DAX measures** for sales calculations and data analysis.

## Power BI Visuals Used

* **Cards** – Displayed key sales KPIs.
* **Map** – Analyzed geographical sales performance.
* **Line Chart** – Showed monthly sales trends.
* **Area Chart** – Visualized sales trends over time.
* **Stacked Column Chart** – Compared sales across different categories.
* **Pie Chart** – Showed payment and transaction distribution.
* **Funnel Chart** – Represented categorical sales information.
* **Table** – Displayed detailed sales and transaction data.
* **Slicers** – Provided interactive filtering.
* **Buttons** – Added navigation and dashboard interactivity.

## Tools & Technologies

* **Power BI**
* **DAX**

## Outcome

The final dashboard provides a **user-friendly and interactive view of mobile sales performance**, making it easier to understand monthly trends, transaction patterns, payment preferences, and location-wise sales performance through dynamic visualizations and DAX-based analysis.
